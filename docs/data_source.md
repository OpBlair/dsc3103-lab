# Data Source classification

## Data Type

The data type is **Structured data**

## Justification

The data is organized in a tabular csv format where each row represents a transaction and each column represents a specific value.

## Variables and What they represent

Varibale    What it Represents
Transaction ID A unique identifier for each transaction 
Item           The product purchased
Quantity       Number of items purchased
Price Per Unit Price of each unit of the purchased item
Total Spent    Total amount spent on the transaction
Payment Method Method used to pay for the item
Location       Where the transaction took place
Transaction Date    Date on which the transaction occured

## Target Variable and Candidate Feature

### Target 
The target variable is **Total Spent** 

### Candidate Feature
The candidate feature variables are:
- Item
- Quantity 
- Price Per Unit 
- Payment Method 
- Location 
- Transaction Date
